01 — RESPONSIVE DESIGN

What is a Media Query?

A media query is a CSS technique that allows a website to change its style according to the screen size, device width, or other device features. It helps us create responsive websites for mobiles, tablets, and desktops.

Why do we use Media Queries?

  • To make websites mobile-friendly.
  • To change font sizes on smaller screens.
  • To adjust spacing and layouts.
  • To provide a better user experience on every device.

Example: Media Query

/* Default style */
.box {
    background: purple;
    padding: 30px;
}

/* For screens 600px or smaller */
@media (max-width: 600px) {
    .box {
        background: deeppink;
        padding: 15px;
    }
}

02 — LAYOUT SYSTEMS

Flexbox vs CSS Grid

Flexbox and Grid are CSS layout systems used to arrange elements on a webpage. The main difference is how they manage rows and columns.

↔

CSS Flexbox

Flexbox is a one-dimensional layout system. It arranges elements in a row OR a column.

  • Works in one dimension.
  • Great for navigation bars.
  • Useful for buttons and aligned items.
▦

CSS Grid

CSS Grid is a two-dimensional layout system. It arranges elements in rows AND columns.

  • Works in two dimensions.
  • Great for page layouts.
  • Useful for galleries and dashboards.
